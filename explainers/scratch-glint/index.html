亮线永远经过两个固定点：圆心 C，以及光源在盘面上的镜面反射点 O。

拖动 C，亮线跟着转，但始终穿过这两点。把 h 调大，亮带会变宽；把 δ 调小，亮带会变细。原因分别在 §2 和 §4。

§1 · 反射锥

一根划痕只把光反射到一个圆锥上

划痕的截面近似一段圆柱面，面上每一点的法向 \(\hat n\) 都垂直于槽的方向 \(\hat s\)。代入镜面反射公式：

$$\hat r=\hat d-2(\hat d\cdot\hat n)\,\hat n,\qquad \hat n\perp\hat s\ \Longrightarrow\ \hat r\cdot\hat s=\hat d\cdot\hat s$$

反射只改变垂直于槽的分量，沿槽的分量原样保留。

弧形槽底把垂直分量散成一个扇面（左图）。沿槽分量固定为 \(\cos\beta\)（右图）。两者合起来，出射光铺满一个以槽为轴、半顶角为 \(\beta\) 的圆锥。几何衍射里棱边的 Keller 锥是同一个几何关系。

所以某点的划痕在眼睛里发亮，当且仅当眼睛方向 \(\hat r\) 落在这个圆锥上：

$$\hat d\cdot\hat s=\hat r\cdot\hat s$$

一个方程、两个未知数 (x, y)：亮点在盘面上连成一条曲线，而不是一片区域。

§3 · 沟槽方程 · 视频 9:02–9:07、12:22–12:37

四次曲线，以及平方混进来的假分支

代入后得到视频屏幕上的方程（分子已合并）：

$$\frac{(xv-yu)+h\tan i\,(x-u)}{\sqrt{x^2+h^2+(y+h\tan i)^2}}=(x-u)\sin i$$

两边平方，得到 x、y 的四次曲线。展开后 \(h^2\) 项相消，方程对 h 只剩一次：

$$h=\frac{(x-u)^2\sin^2 i\,(x^2+y^2)-(xv-yu)^2}{2(x-u)\tan i\,\big[(xv-yu)-(x-u)\,y\sin^2 i\big]}$$

h→∞ 要求分母趋于 0，得到两个因子。平方的同时，也把 \(\hat d\cdot\vec s=-\hat r\cdot\vec s\) 并了进来。这等于沿槽分量反号，不对应任何真实反射。图中紫色虚线就是这一支，它在大 h 下贴向竖线 x = u：

$$x-u\approx-\frac{u\,(v-y)}{2h\tan i}$$

分母的两个因子各有来处：方括号 = 0 是真分支的极限，即双曲线；x − u = 0 是假分支的极限。

“x = u 代回原式只剩圆心”，这句话只对未平方的方程成立。平方后的方程在有限 h 下确实有一整支曲线贴着 x = u。模拟器如果直接画平方后的方程，就会把这一支也画出来。

§4 · 为什么 h² 必然相消

零阶项恒为零，曲线由 1/h 阶决定

眼睛越远，从盘上各点看眼睛的方向越接近同一个方向 \(\hat r_0\)，也就是 O 点的镜面反射方向：

$$\hat r=\hat r_0+O\!\left(\tfrac{R}{h}\right),\qquad \hat r_0=(0,\,-\sin i,\,\cos i)$$

\(\hat d\) 与 \(\hat r_0\) 只差 z 分量，而 \(\vec s\) 没有 z 分量：

$$(\hat d-\hat r_0)\cdot\vec s=(0,\,0,\,-2\cos i)\cdot(s_x,\,s_y,\,0)=0$$

于是 \(f=\hat d\cdot\hat s-\hat r\cdot\hat s=g(Q)/h+O(1/h^2)\)。零阶对所有点自动成立，平方后两边的 \(h^2\) 系数必然相同。左边与右边分别是：

$$\begin{aligned}&(x-u)^2\tan^2 i\\ &(x-u)^2\sin^2 i\,(1+\tan^2 i)=(x-u)^2\tan^2 i\end{aligned}$$

真正决定曲线的是 \(g(Q)=0\)，也就是 §5 的双曲线。

同一事实还有一个物理后果：f 在整张盘上按 1/h 缩小，右图中是斜率 −1 的直线。真实划痕有散射角 δ，亮的条件是 \(|f|\lesssim\delta\)，所以亮带宽度大约正比于 \(\delta h\)。

圆心附近的亮带会张成楔形。那里 \(f\approx(\hat d-\hat r_C)\cdot\hat s\) 只取决于方位角，楔形的半张角约为 \(\delta/|(\hat d-\hat r_C)_{xy}|\)（下标 xy 指水平分量），h 越大，楔形越宽。

双曲线只在 R ≪ h ≪ R/δ 的中间区间看得到。h 太小，曲线偏离双曲线；h 太大，整张盘都亮，条纹消失。

§5 · 标准化 · 视频 12:25–12:34

平移、缩放、翻转，得到 y = 1/x

  1. 原式
    $$xy-\frac{v}{\sin^2 i}\,x+\frac{u}{\tan^2 i}\,y=0$$
  2. 平移：配方，把中心 K 移到原点
    $$\Big(x+\frac{u}{\tan^2 i}\Big)\Big(y-\frac{v}{\sin^2 i}\Big)=-\frac{uv\cos^2 i}{\sin^4 i}$$
  3. 缩放：右边等于 \(-\operatorname{sgn}(uv)\,k^2\)
    $$k=\frac{\sqrt{|uv|}\,\cos i}{\sin^2 i}$$
  4. 翻转：uv > 0 时 y 轴反向
    $$\begin{aligned}x'&=\frac{x+u/\tan^2 i}{k}\\ y'&=\operatorname{sgn}(-uv)\,\frac{y-v/\sin^2 i}{k}\end{aligned}\ \Longrightarrow\ x'y'=1$$

核对：C(u, v) 代入得 \(uv\,\big(1-\tfrac{1}{\sin^2 i}+\tfrac{\cos^2 i}{\sin^2 i}\big)=0\)；O(0, 0) 显然也在曲线上。

O 和 C 还在同一支上：

$$\begin{aligned}O-K&=\frac{(u\cos^2 i,\ -v)}{\sin^2 i}\\ C-K&=\frac{(u,\ -v\cos^2 i)}{\sin^2 i}\end{aligned}$$

两者各分量同号，落在同一象限。标准化后，O 位于 \(x'=\operatorname{sgn}(u)\sqrt{|u/v|}\,\cos i\)，C 位于 \(x'=\operatorname{sgn}(u)\sqrt{|u/v|}\,/\cos i\)。

盘上看到的亮线，就是 y = 1/x 其中一支上，从 O 经过 C 的那一段及其延伸。

§6 · 两个极限 · 视频 9:47

小入射角时像直径，掠射时折成直角

把双曲线方程乘以 \(\sin^2 i\)：

$$\sin^2 i\;xy-vx+u\cos^2 i\;y=0$$
i → 0
\(vx=uy\)，即直线 OC。中心 K 跑到无穷远，双曲线的一支被拉直。亮线成为一条真正的直径，方向指向光源的镜面反射点 O。
i → 90°
\(x\,(y-v)=0\)。K 趋于 (0, v)，亮线折成两段：沿入射面的 x = 0，以及过圆心的 y = v。
u = 0
\(x\,(y-v/\sin^2 i)=0\)。圆心在入射面内，也就是正对着看。
v = 0
\(y\,(x+u/\tan^2 i)=0\)。

u = 0 或 v = 0 时双曲线退化为两条直线，其中过 O、C 的那条对任何 i 都是直径。

视频说“像直径”，准确的说法是：亮线是双曲线过 O、C 的那一支。i→0 时它变成直线 OC，i→90° 时变成直角折线。

§7 · 对照原笔记

本页新增或修正的内容

  1. 亮线必过 O，不只在 h→∞ 时。E 取在 O 的镜面反射线上，任意有限 h 下 O 点对所有方向的槽都满足条件。
  2. 因子 x − u 是假分支的极限位置。偏移量 \(x-u\approx-u(v-y)/(2h\tan i)\)，与数值求根一致。“代回只剩圆心”只对未平方的方程成立。
  3. O、C 在双曲线的同一支上。标准化后两点的横坐标分别是 \(\sqrt{|u/v|}\cos i\) 和 \(\sqrt{|u/v|}/\cos i\)（带 sgn u）。
  4. i → 90° 的另一端极限。\(x(y-v)=0\)，是一条直角折线，与 i → 0 的直线 OC 相对。
  5. 双曲线的适用区间是 R ≪ h ≪ R/δ。失配 f 整体按 1/h 缩小，眼睛太远反而整盘都亮。
  6. 反射锥的一行证明。\(\hat n\perp\hat s\Rightarrow\hat r\cdot\hat s=\hat d\cdot\hat s\)。视频直接用了这个结论，没有推导。

符号验算（sympy）：h² 系数恒为 0；h¹ 系数等于 \(2\tan i\,(x-u)\big[(xv-yu)-(x-u)y\sin^2 i\big]\)；配方恒等式与圆心代入均化简为 0。数值验算：h = 20、100、1000 时，真分支到双曲线的最大距离约为 0.11、0.085、0.008，假分支到 x = u 的偏移按 1/h 缩小。
